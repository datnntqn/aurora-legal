# safari-legal

Marketing + legal site for [Aurora — Safari Dark Themes](https://apps.apple.com/us/app/aurora-safari-dark-themes/id6751903540).

Live: https://datnntqn.github.io/safari-legal/

## Pages

- `index.html` — landing page (marketing)
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Service
- `support.html` — FAQ + contact

## Tech

Vanilla HTML5 + CSS3 + JS. No framework, no build step. Just edit and push.

## Local preview

```
python3 -m http.server 8080
```

Open http://localhost:8080.

## Deploy

Pushed to GitHub `main` branch — Pages serves it automatically. `.nojekyll` disables Jekyll processing.
